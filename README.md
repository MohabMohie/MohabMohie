## SHAFT_ENGINE

[SHAFT_ENGINE](https://github.com/ShaftHQ/SHAFT_ENGINE) is the unified test-automation engine I create and maintain. One Java framework covers web, mobile, API, CLI, database, and desktop end-to-end testing, so a team can stop rebuilding drivers, waits, assertions, configuration, and evidence for every new project. Start with the [user guide](https://shafthq.github.io/).

## ChaosEngine

[ChaosEngine](https://github.com/ShaftHQ/SHAFT_ENGINE/tree/main/chaos-engine) is my provider-neutral agent skill-router and working-policy overlay. It ships inside SHAFT_ENGINE, in that tree, not as a separate product. Agents load it as the working contract before they change the project, on any host, so the policy stays with the repository instead of with one model vendor. It is a working-policy overlay, not a fault-injection tool.
