The unified Java test-automation engine for web, mobile, API, CLI, database, and desktop. Teams stop rebuilding drivers, waits, assertions, and evidence on every new project.

**[Open SHAFT_ENGINE](https://github.com/ShaftHQ/SHAFT_ENGINE)** · **[User guide](https://shafthq.github.io/)**

### ChaosEngine

The provider-neutral agent skill-router and working-policy overlay. It ships **inside** [SHAFT_ENGINE](https://github.com/ShaftHQ/SHAFT_ENGINE/tree/main/chaos-engine), not as a separate product. Agents load it as the working contract before they change the project. It is a working-policy overlay, not a fault-injection tool.

**[Open the ChaosEngine tree](https://github.com/ShaftHQ/SHAFT_ENGINE/tree/main/chaos-engine)**

> Reliable Java test automation, from first intent to production-grade evidence.
>
> A portable working contract that turns software agents into disciplined engineering partners.
